Key Features

AWS S3 image uploads

Generate secure, short-lived presigned URLs so clients can upload post images directly to S3-compatible object storage.

AWS CloudFront image delivery

Serve uploaded post images through a CloudFront domain for fast delivery to users.

Application monitoring

Instrument FastAPI requests, Pydantic validation, and SQLAlchemy database activity with Pydantic Logfire.

Social interactions

Support user follows, personalized feeds, post likes, and comments through dedicated API endpoints.
